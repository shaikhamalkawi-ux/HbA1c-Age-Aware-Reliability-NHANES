# R1.2 public-safe aggregate summary

This directory summarizes the major-revision sensitivity analyses reported in the revised manuscript. These analyses were added after the original submission and are treated as **post hoc sensitivity analyses**, not prospectively prespecified confirmatory tests.

Only aggregate results are included here. Participant-level NHANES analytic tables, predictions, calibration residuals, and split ledgers are not redistributed.

See summary.csv for machine-readable central values.

Main interpretation:
- hard-age OLS did not demonstrate a point-prediction benefit over pooled OLS;
- a smaller age-coverage spread did not necessarily improve minimum-group coverage;
- subgroup calibration conclusions depended on calibration partition and source split;
- both temporal evaluations remain same-program NHANES transport, not independent clinical-system validation.
