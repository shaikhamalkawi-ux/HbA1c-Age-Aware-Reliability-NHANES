# v1.0.1 release notes

## Purpose

This is a production/archival patch release for the public reproducibility materials associated with:

**Age-Aware Reliability of HbA1c Prediction Across NHANES Cycles: Leakage-Free Evaluation, Conformal Calibration, and Temporal Transport**

It does **not** change any locked scientific result, cohort, model, bootstrap result, conformal calibration rule, temporal evaluation, figure data, table value, or claim boundary.

## Changes relative to v1.0.0

- Aligns the README triglyceride boundary wording with the verified source criterion: the 25 missing-Friedewald-LDL records had triglycerides **greater than 400 mg/dL**.
- Updates `CITATION.cff` to version **1.0.1** for Zenodo archival publication.
- Adds these release notes so the archival delta is explicit.

## Scientific status

The registered scientific verification remains closed PASS. No scientific analysis was reopened for this patch release.

## Public-data policy

Raw NHANES XPT files, participant-level analytic tables, participant-level predictions, and private internal research archives remain excluded. Public materials contain source-reconstruction certificates, aggregate derived outputs, frozen model/calibration identity records, the assay/source ledger, public-shareable legacy verification summaries, and verification scripts.
