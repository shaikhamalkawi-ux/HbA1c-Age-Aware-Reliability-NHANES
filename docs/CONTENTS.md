# Included and excluded materials

The repository publishes public-safe documentation, verification code, exact source identities, aggregate outputs, and frozen certificates. Participant-level material remains excluded.

Public aggregate outputs include the original submitted-analysis files under derived_outputs/ and the public-safe R1.2 summary material under derived_outputs/revision_r1_2/.

Intentionally excluded:
- raw NHANES XPT files;
- participant-level cohorts and reconstructed participant tables;
- participant-level OOF predictions and interval endpoints;
- split/role ledgers containing participant identifiers;
- private research archives and machine-specific paths;
- manuscript PDFs/source, journal correspondence, reviewer packages and chat-transfer archives;
- credentials, tokens and private contact files.

## Current publication route

The current manuscript cites this GitHub repository as its public reproducibility resource. No Zenodo deposit or DOI is required for the resubmission.
