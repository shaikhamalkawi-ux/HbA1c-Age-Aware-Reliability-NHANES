# Publication archive release v1.0.3

Published 26 November 2026. This release accompanies the published article, [Bioengineering 2026, 13(11), 1373](https://doi.org/10.3390/bioengineering13111373), and the independent [Zenodo research archive](https://doi.org/10.5281/zenodo.24542980).

Release assets mirror the Zenodo deposit: the complete archive ZIP, published article PDF, final publisher supplementary PDF, original publisher supplementary ZIP, Aggregate Evidence ZIP, inventory, SHA-256 manifest, citation file, README, and verification report. The archive ZIP includes the publisher supplementary package, extracted aggregate evidence and code, public-safe repository snapshot, and proof-derived figure assets.

The source tree remains text-only. The public archive omits participant-level analytic tables and predictions, raw NHANES files, private correspondence, and credentials. The aggregate verifier checks package hashes and arithmetic; the deposit does not support an end-to-end rerun of every experiment because some generating scripts and original fitted CQR learner objects are unavailable. See the release assets' `README.md` and `VERIFICATION_REPORT.md` for detailed provenance, licensing, and scientific limits.
